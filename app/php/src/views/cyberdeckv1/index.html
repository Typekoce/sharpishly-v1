05 // Fabrication Pipeline

0% COMPLETE
  • PHASE 01 — MECHANICAL
    Chassis & enclosure

    Print or machine body, verify display cutout, mount ortholinear plate, install rubber feet.

  • PHASE 01 — MECHANICAL
    Thermal interface

    Apply thermal pads to SoC and PMIC; verify clearance under heatsink or vapor chamber.

  • PHASE 02 — POWER
    4S LiFePO₄ harness

    Assemble balance leads, fuse, BMS connection, and main power switch. Verify polarity.

  • PHASE 02 — POWER
    Buck / boost bring-up

    Power rails at 5 V / 3.3 V under no-load; check ripple with scope probe.

  • PHASE 03 — COMPUTE & IO
    SBC / module seating

    Seat compute module, connect eMMC/SD, HDMI/DSI, USB hub, and GPIO header.

  • PHASE 03 — COMPUTE & IO
    Keyboard matrix & encoder

    Flash QMK/ZMK, verify matrix scan, rotary encoder, and status LEDs.

  • PHASE 04 — RF & VALIDATION
    SDR / LoRa bay

    Install radio module, antenna, run mesh-ping and spectrum check. Confirm isolation from power rails.

  • PHASE 04 — RF & VALIDATION
    Full system soak

    2-hour load test at target brightness and radio duty cycle; log temps and voltage sag.
